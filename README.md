# KnesRedux

KSP2 Redux port of [AstroWell/Knes](https://github.com/AstroWell/Knes).

This port is being undertaken with permission from the original author. Original Knes models, textures, part designs and branding remain credited to Stéphane Colombain (AstroWell / Well).

## Status

Initial conversion pipeline and compatibility analysis.

The first validation family will be **Diamant**, then the conversion pipeline will be expanded to the remaining Knes families.

## Source target

- KSP1 source: Knes 1.9.9
- KSP2 target: KSP2 v0.2.2.0 + KSP2 Redux
- Tooling: KSP2 Redux SDK / KSP1 Mod Converter
